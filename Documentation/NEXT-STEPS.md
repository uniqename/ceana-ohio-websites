## Recommended Path to Launch

### Option A – Fastest (Recommended for most chapters)
1. Create accounts on **Squarespace**, **Wix**, or **WordPress.com**.
2. Choose a clean nonprofit / community template.
3. Apply the color palette and fonts from the Design System.
4. Copy-paste and adapt the sample content.
5. Add real photos, leadership names, and contact details.
6. Connect a domain (e.g. columbusewes.org or cincyewes.org).
7. Set up a simple contact form and optional donation button (PayPal, Stripe, or Givebutter).

### Option B – Developer / Custom
1. Use the provided HTML as a starting point.
2. Host on Netlify, Vercel, GitHub Pages, or any static host (free tiers available).
3. Or convert to WordPress / Webflow for easier ongoing editing by non-technical volunteers.
4. Add a real form backend (Formspree, Basin, Netlify Forms, or Google Forms embed).

### Option C – Shared Template Approach
Keep both sites visually consistent by starting from the same design system and content structure. This reinforces the “local chapter of CEANA” identity while allowing local personality.
