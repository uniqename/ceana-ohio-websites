HOW TO OPEN ON A MAC (or any computer)

1. Unzip this folder if it is still zipped.

2. Open the folder for the chapter you want:
   - Columbus-Ewe-Habobor
   - Cincinnati-Dayton

3. Double-click the file named:
      index.html

4. The website will open in your browser (Safari, Chrome, etc.).
